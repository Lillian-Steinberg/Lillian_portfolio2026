# Lillian_portfolio2026

A responsive photography portfolio site for Lillian Steinberg. The landing page features a full-width image hero with right-aligned overlay text, followed by five alternating checkerboard project rows. Each row pairs a three-image gallery with a story panel.

## Preview locally

Open `index.html` in a browser. The page uses Google Fonts and Unsplash-hosted photography, so an internet connection is needed for the typefaces and images.

## Customize

- Replace the Unsplash image URLs and alt text in `index.html` with your own photography.
- Update the project names, captions, and contact email to match your work.
- Adjust layout, colors, and responsive styles in `styles.css`.
