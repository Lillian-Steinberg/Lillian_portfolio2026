# Lillian_portfolio2026

A responsive photography portfolio site for Lillian Steinberg. It features a full-width image hero, five alternating project rows with a two-thirds image area and one-third text panel, individual project pages with distinct image mosaics, and a footer image overlapped by a link to a dedicated contact page.

## Preview locally

Open `index.html` in a browser. The page uses Google Fonts and Unsplash-hosted sample photography, so an internet connection is needed for the typeface and images.

## Customize

- Replace the Unsplash image URLs and alt text in `index.html` and `work-01.html` through `work-05.html` with your own photography.
- Update project names, captions, and the email address in `contact.html` to match your work.
- Adjust layout, colors, and responsive styles in `styles.css`, `project.css`, `site-updates.css`, and `contact.css`.
