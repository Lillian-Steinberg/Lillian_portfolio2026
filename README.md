# Lillian_portfolio2026

A responsive photography portfolio site for Lillian Steinberg. The landing page features a full-width image hero with right-aligned overlay text, followed by five alternating checkerboard project rows. Each row links to its own project page with a distinct, overlapping image mosaic. A full-width image anchors the footer.

## Preview locally

Open `index.html` in a browser. The page uses Google Fonts and Unsplash-hosted sample photography, so an internet connection is needed for the typefaces and images.

## Customize

- Replace the Unsplash image URLs and alt text in `index.html` and `work-01.html` through `work-05.html` with your own photography.
- Update project names, captions, and the contact email to match your work.
- Adjust layout, colors, and responsive styles in `styles.css` and `project.css`.
